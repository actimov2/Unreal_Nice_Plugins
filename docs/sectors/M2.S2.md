## Binding Design Decisions (from M2.S1 ADR follow-up)

These are NOT open for re-litigation by the upcoming planning pass —
they are the load-bearing decisions the M2.S1 architect-verifier already
locked in. The planning pass refines *how*, not *whether*.

1. **Extract `ICategoryProvider` interface.** `FMeshVertexProvider`
   becomes the first concrete impl. Interface lives in
   `Source/OptimizePrime/Public/Analyzer/ICategoryProvider.h`.
2. **Add `FNaniteEligibilityProvider`** as the second concrete impl. Flags
   high-tri non-Nanite static meshes (candidate threshold:
   `tris > 100,000 && !bAllowMeshNanite`). Final threshold delegated to
   the deep-interview pass.
3. **Promote severity thresholds to `UDeveloperSettings`.** Replace the
   `static constexpr SeverityYellow/Red` block in
   `MeshVertexProvider.cpp` with a `UOptimizePrimeSettings` UCLASS backed
   by `Config/DefaultEditor.ini`. Settings page lives under
   `Edit → Project Settings → Plugins → OptimizePrime`.
4. **`FAnalyzerService` owns `TArray<TUniquePtr<ICategoryProvider>>`** —
   not `TUniquePtr<FMeshVertexProvider>` anymore. `ScanWorld()` iterates
   providers and concatenates rows; each row carries a category tag.
5. **UI extension: category column or tabbed filter.** Decision deferred
   to deep-interview; design must allow ≥2 categories to coexist in the
   `SHeavinessReportList`.
6. **No UMG migration in M2.S2.** Slate-only stays. UMG is M2.S2-polish
   (separate sector) if the widget grows beyond a tabbed list.

## Definition of Done (placeholder; refine in deep-interview)

1. `ICategoryProvider.h` exists and declares the contract.
2. `FMeshVertexProvider` implements `ICategoryProvider` (refactor, no

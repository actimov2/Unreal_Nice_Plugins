# M1.S3 — Verify `regenerate.ps1` From a Clean State

## Plugin

`host` (no submodule edits).

## Preconditions

- M1.S1 has landed (so the host has a real plugin edit pin to regenerate
  against).
- `Get-Process UnrealEditor -ErrorAction SilentlyContinue` returns null.

## Definition of Done

1. From a clean working tree at host root, delete `HostProject/Binaries/`,
   `HostProject/Intermediate/`, and any stale `*.sln` at host root.
2. Run `scripts/regenerate.ps1` from host root.
3. The script exits 0.
4. `HostProject.sln` is regenerated and the `SamplePlugin` module is wired
   into the project (`Select-String -Path HostProject/Intermediate/ProjectFiles/HostProject.vcxproj -Pattern 'SamplePlugin'`
   returns at least one match). UBT writes module references into the
   per-project `.vcxproj`, not the top-level `.sln`.
5. No errors in the regenerate output stream.

## Verification

- Capture the regenerate stdout/stderr to
  `.omc/research/m1s3-regenerate-log.txt`.
- Re-running `scripts/regenerate.ps1` a second time exits 0 with no diff
  (idempotency check).

## ACs Touched

- AC3 — workflow files exist and the toolchain is wired.

## Notes

- This sector runs from host root and does **not** call
  `scripts/sector-commit.ps1` — there is no submodule pin to update.
- It is intentionally lightweight; its purpose is to catch regressions in
  the host scaffold (path issues, missing `.uproject`, broken UBT detection).

## Plugin

`SamplePlugin` (`HostProject/Plugins/SamplePlugin`).

## Definition of Done

The plugin emits a `LogSamplePlugin started` line on module startup.

### File edits (executor will apply these during the `next` run)

1. `HostProject/Plugins/SamplePlugin/Source/SamplePlugin/Public/SamplePlugin.h`

   Add at file scope (outside the class):

   ```cpp
   DECLARE_LOG_CATEGORY_EXTERN(LogSamplePlugin, Log, All);
   ```

2. `HostProject/Plugins/SamplePlugin/Source/SamplePlugin/Private/SamplePlugin.cpp`

   Add at file scope:

   ```cpp
   DEFINE_LOG_CATEGORY(LogSamplePlugin);
   ```

   And inside `FSamplePluginModule::StartupModule()`, before any other
   startup code:

   ```cpp
   UE_LOG(LogSamplePlugin, Log, TEXT("LogSamplePlugin started"));
   ```

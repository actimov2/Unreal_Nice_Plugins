## MeshVertexProvider Null-Guard Snippet (inlined — CRITICAL)

This exact guard MUST appear in `MeshVertexProvider::Scan()`. Do not omit either condition.

```cpp
const FStaticMeshRenderData* RD = SM->GetRenderData();
if (!RD || RD->LODResources.Num() == 0) { continue; }
```

Full skip block with logging:

```cpp
const FStaticMeshRenderData* RD = SM->GetRenderData();
if (!RD || RD->LODResources.Num() == 0)
{
    UE_LOG(LogOptimizePrime, Verbose, TEXT("OptimizePrime: skipping '%s' — no render data or LODs"),
        *Actor->GetActorLabel());
    continue;
}
const int32 VertexCount = static_cast<int32>(RD->LODResources[0].GetNumVertices());
```

# M1.S2 — Tag `SamplePlugin` v0.1.0 + AC2 Rollback Prep

## Plugin

`SamplePlugin`.

## Preconditions

- M1.S1 has landed on `SamplePlugin`'s `dev` branch.
- The host repo carries the corresponding pin commit on its current
  branch.
- `Get-Process UnrealEditor -ErrorAction SilentlyContinue` returns null.

## Definition of Done

1. `SamplePlugin`'s `main` branch is fast-forwarded from `dev` and tagged
   `v0.1.0` via `scripts/plugin-version.ps1 -Plugin SamplePlugin -Bump minor`.
2. The tag and `main` are pushed: `git -C HostProject/Plugins/SamplePlugin
   push origin main --follow-tags` (the script does this).
3. `git -C HostProject/Plugins/SamplePlugin tag --list` shows both
   `v0.0.1` (baseline) and `v0.1.0`.
4. AC2 rollback is verified: with `v0.0.1` checked out inside the
   submodule + `regenerate.ps1` + editor open, the Output Log does **not**
   contain `LogSamplePlugin started`. Restore by checking out `v0.1.0`.

## Verification

- `git -C HostProject/Plugins/SamplePlugin describe --tags --abbrev=0 main`
  prints `v0.1.0`.
- The host repo's submodule pointer is unchanged after rollback (it points
  to the M1.S1 SHA, not to `v0.0.1` or `v0.1.0` directly).
- Evidence written to `.omc/research/ac2-rollback-evidence.md`.

## ACs Touched

- AC2 — rollback demo.
- AC4 — versioning convention exercised end-to-end.

## Notes

- This sector does **not** invoke `scripts/sector-commit.ps1`; no host pin
  changes. The plugin-version script handles its own pushes.
- Tag promotion is FF-only by contract; if `main` has diverged from `dev`,
  the script exits 20 and points to `docs/VERSIONING.md §Branch Discipline`.

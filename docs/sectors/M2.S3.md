## Definition of Done

1. Toolbar button registered by M2.S1 grows a sub-menu OR a second toolbar
   button is registered that opens a docked tab `OptimizePrimeLogScanner`.
2. Tab contains: `Scan Log` button, `Scan Crashes` button, `Export Report`
   button, mode toggle (Live / Crash), and `SLogWarningList` (categorized).
3. `Scan Log` reads `<ProjectDir>/Saved/Logs/<ProjectName>.log` (last 5000
   lines), runs all `FLogPattern` matchers, returns
   `FLogScanReport` with rows grouped by `EWarningCategory`.
4. `Scan Crashes` finds the most-recently-modified directory under
   `<ProjectDir>/Saved/Crashes/UECC-Windows-*` and renders
   `CrashContext.runtime-xml` ErrorMessage + tail-50 of `<ProjectName>.log`.
5. List groups warnings by category with count badge per group; empty state
   renders "No warnings found" / "No crash folders found".
6. `Export Report` writes a markdown file to
   `<ProjectDir>/Saved/OptimizePrime/log-report-<UTC-yyyyMMdd-HHmmss>.md`
   containing the same data Slate shows (paste-friendly for Claude/AI).
7. `LogOptimizePrime` tag prints `LogScanner: scanned N lines, found K warnings
   in M categories` after each scan.
8. `scripts/sector-commit.ps1 -Plugin OptimizePrime -SectorId M2.S3 -BdId <bd>`
   exits 0; both pushes land; MILESTONES.md row flips to `[x]`.

|---|---|---|
| `NaniteTranslucent` | `Invalid material \[(.+?)\] used on Nanite static mesh \[(.+?)\]` | "Disable Nanite on mesh OR change material to Opaque/Masked" |
| `MissingReference` | `(LoadPackage: SkipPackage|Failed to find object): (.+)` | "Asset moved/deleted; restore at original path or fix refs" |
| `VirtualTexture` | `VTStacks\.Num\(\) == .* VTStacks` | "MaterialParameterCollection missing — duplicate MPC back to original path" |

## Service Snippet (inlined — CRITICAL paths)

```cpp
FLogScanReport FLogScannerService::ScanLiveLog(int32 TailLines) const
{
    const FString LogPath = FPaths::Combine(
        FPaths::ProjectSavedDir(), TEXT("Logs"),
        FApp::GetProjectName() + FString(TEXT(".log")));

    FString FullText;
    if (!FFileHelper::LoadFileToString(FullText, *LogPath))
    {
        UE_LOG(LogOptimizePrime, Warning,
            TEXT("LogScanner: failed to read %s"), *LogPath);
        return {};
    }

    TArray<FString> Lines;
    FullText.ParseIntoArrayLines(Lines);
    const int32 Start = FMath::Max(0, Lines.Num() - TailLines);

    FLogScanReport Report;
    Report.Timestamp = FDateTime::UtcNow();
    Report.SourcePath = LogPath;
    Report.LinesScanned = Lines.Num() - Start;

    const auto& Patterns = FLogPattern::GetBuiltInPatterns();
    for (int32 i = Start; i < Lines.Num(); ++i)
    {
        for (const FLogPattern& P : Patterns)
        {
            FRegexMatcher M(P.Pattern, Lines[i]);
            if (M.FindNext())
            {
                FLogWarning W;
                W.Category = P.Category;
                W.Message = Lines[i].Left(240);
                W.FixHint = P.FixHint;
                W.LineNumber = i + 1;
                Report.Warnings.Add(W);
                break; // first matching pattern wins per line
            }
        }
    }
    return Report;
}
```

## Notes

- **Reuses M2.S1 infrastructure:** same module, same Build.cs, same toolbar
  registration pattern. M2.S3 only adds a second tab spawner — no engine
  module additions, no new dependencies.
- **No auto-fix in M2.S3** (deferred): `FixHint` is text-only. Auto-fix
  recipes (e.g. one-click "Disable Nanite on this mesh") arrive in a
  potential M2.S4 sector, with an `FFixRecipe` interface and per-category
  recipe registry.
- **No background watcher in M2.S3** (deferred): scans are explicit
  button-press only. File-system watcher for live log + crash folder is
  M2.S4 territory; keeps M2.S3 small and easy to verify.
- **Markdown export format:** front-matter (timestamp, source, line count)
  + one `## <Category>` section per group + bulleted warnings with
  `Line N:` prefix and indented `> Fix: ...` quote. Paste-friendly for
  feeding to Claude / AI assistants.
- **Cross-reference:** No deep-interview spec for M2.S3 yet — author
  one in `.omc/specs/deep-interview-optimizeprime-m2s3.md` if scope
  expands beyond this doc.
